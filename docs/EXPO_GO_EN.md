# Run Healthy Garden in Expo Go — from zero

This public jury preview uses branch **`demo/jury-month`**, isolated from the original app. Each reviewer runs their own copy and garden. **No AI key, login, Xcode, Android Studio or Supabase account is needed for the prepared demo.**

## 1. Install prerequisites

- Install **Node.js 24 LTS** from [nodejs.org](https://nodejs.org/en/download).
- Mac: run `git --version`. If Git is missing, run `xcode-select --install`, finish Apple's Command Line Tools installer, then open a new Terminal.
- Windows: install [Git for Windows](https://git-scm.com/downloads/win), then open a **new PowerShell** so the new PATH is loaded.
- Install **Expo Go** on your iPhone or Android phone. Keep Expo SDK 57 pinned in this project; do not upgrade its dependencies to a newer SDK.

## 2. Clone and start — Mac

```bash
cd ~/Documents
git clone --branch demo/jury-month --single-branch https://github.com/MertDemircanYc80/healthy-garden.git healthy-garden-jury
cd healthy-garden-jury/mobile
npm ci
npm start -- --clear
```

## 2. Clone and start — Windows PowerShell

```powershell
Set-Location ([Environment]::GetFolderPath('MyDocuments'))
git clone --branch demo/jury-month --single-branch https://github.com/MertDemircanYc80/healthy-garden.git healthy-garden-jury
Set-Location healthy-garden-jury\mobile
npm.cmd ci
npm.cmd start -- --clear
```

Using `npm.cmd` avoids PowerShell script execution-policy problems. Allow Node.js on **private networks** if Windows Firewall asks. Both platforms should show **Using Expo Go** and a QR code. Leave the terminal running.

If the clone folder already exists, choose a new folder name. Nothing requires deleting your existing changes or resetting `main`.

## 3. Open on your phone

1. Put the computer and phone on the **same Wi-Fi**; disable VPNs.
2. iPhone: scan the QR with Camera and open in Expo Go. Android: use Expo Go's QR scanner.
3. Wait for the first JavaScript bundle. Each reviewer must use the QR generated by **their own computer**. A `192.168…` link from the author's computer is not a permanent download link.

## 4. Try the complete loop

1. Open **30-day demo** from Garden.
2. Choose **Start with day 1 → Finish day 1** to earn **10 daily gold**. Observe the report before any personal goals exist.
3. For a faster start, use **Load first 7 days** from an empty demo: seven records and **70 daily gold**. **Return to empty state → Confirm reset** clears only your demo garden/purchases.
4. Choose **Analyze the first week**. **Prepared AI · offline replay** means the included analysis was prepared in advance; this route makes no new model request.
5. Visit **Goals**, **Coach**, and **Report**. Tap Sleep, Feed time or Instagram to see their own histories.
6. **Open day 8 → Finish day 8**. Every completed data day pays **10 gold**; completed goals pay **2×** their base plan reward. Repeated loads do not pay twice.
7. Tap an empty garden plot to buy/plant a Daisy. Buy a **Water refill** in Market, switch to **Water** mode and tap the plant.
8. **Open day 9** to see overnight growth. Continue to the 30th day; watered plants grow, unwatered plants rest.

First-week gold is seven daily rewards, not a separate signup grant. Existing saves receive missing daily rewards once, preserving purchases and plants. Higher goal rewards apply to future completions; old goal receipts are not multiplied retroactively.

## Optional: live Gemini and terminal weeks

Use your **own** Gemini API key. In `mobile/`, run `npm run demo:setup` (Windows: `npm.cmd run demo:setup`), paste at the hidden prompt and press Enter. On Mac, `-- --clipboard` reads the copied key after confirmation. Keys stay local and are never included in Expo's bundle or GitHub.

Keep `npm run coach` and `npm start -- --clear` running in separate terminals after setup. In a third terminal, run `npm run demo -- week 1`, then `week 2`, `week 3`, `week 4`, `week 5` (last two days). Use `next`/`finish` for daily scenes. Replace `npm` with `npm.cmd` on Windows. Each weekly command reports whether the app acknowledged the import. Without a key, use setup `-- --no-key` and weekly commands `--prepared` explicitly.

## If connecting fails

- Confirm **Using Expo Go**, not a development-client QR. Restart a stopped server; old QRs expire.
- Same Wi-Fi, no VPN, private-network firewall permission. School/hotel networks may isolate devices.
- Alternative for the prepared demo: install `@expo/ngrok` globally (`npm install --global @expo/ngrok`; Windows `npm.cmd`) and start with `npm start -- --tunnel --clear`. **This tunnels Expo only, not the local AI gateway on port 8877.** Keep the server/computer running.
- If a port is busy, stop the old Expo or accept a free port; scan the new QR.
- To update an existing clean checkout: `git status`, `git pull --ff-only`, `npm ci`, then restart Expo with `--clear`. Commit local work or clone separately if the tree is dirty; do not discard it.

The demo combines [public PMData wearable records and explicitly fictional companion fields](../datasets/README.md). Native HealthKit/automatic iOS Screen Time are not required or claimed by this Expo Go route.
