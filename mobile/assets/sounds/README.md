# Original garden sound effects

Generated by `mobile/scripts/make-garden-sounds.py` specifically for Healthy Garden.
No external samples or recordings. Deterministic mono 24 kHz, 16-bit PCM WAV:

- `water.wav`: 0.62 seconds, filtered pouring noise with soft droplets.
- `fertilize.wav`: 0.40 seconds, brief granular sprinkle/crunch.
- `plant.wav`: 0.34 seconds, low soil thud with a little texture.

Each clip has an attack/release envelope and a peak below -6 dBFS. The app plays
at 0.28 volume (combined peak approximately -17.4 dBFS), one effect at a time.
