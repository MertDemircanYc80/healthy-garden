# Original garden sound effects

Generated by `mobile/scripts/make-garden-sounds.py` for Healthy Garden, with no
external samples or recordings. Mono 48 kHz, 16-bit PCM WAV. All voices are smooth
sine sweeps; there is no white noise or granular crackle.

- `water.wav`: 0.62 seconds, overlapping rounded droplets; 700 Hz low-pass.
- `fertilize.wav`: 0.40 seconds, soft descending sine sprinkles; 850 Hz low-pass.
- `plant.wav`: 0.34 seconds, low rounded thud; 300 Hz low-pass.

Each voice uses raised-cosine fades. A fourth-order Butterworth low-pass removes
high-frequency edges, followed by a final fade to exact zero at both file boundaries.
Asset peaks are -13.2 to -9.9 dBFS. At the app's 0.28 playback volume, combined peaks
are approximately -24.2 to -21.0 dBFS. Effects play one at a time.
